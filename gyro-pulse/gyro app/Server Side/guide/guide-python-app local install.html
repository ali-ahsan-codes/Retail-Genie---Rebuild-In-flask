🔄 Gyro Pulse – Windows Setup

Complete installation & run guide for a new Windows computer

1. Install Prerequisites one‑time

  • Python 3.8+ – Download
    ✔ During installation, check “Add Python to PATH”.
  • MySQL Community Server 8.0 – Download
    ✔ Choose the MSI installer. Remember the root password you set.

2. Get the Project Files

  • Copy the entire project folder (containing app.py, config.json, templates/ etc.) to your computer, e.g., C:\gyropulse.
  • If you received a ZIP archive, extract it to any location.

3. Create Virtual Environment

Open Command Prompt as Administrator and navigate to the project folder.

python -m venv .venv .venv\Scripts\activate
💡 Tip: You’ll see (.venv) at the start of the prompt – that means the environment is active.

4. Install Python Dependencies

Make sure the virtual environment is active, then run:

pip install -r requirements.txt pip install cryptography # (if you get an auth error)

5. Set Up MySQL Database

  1. Start the MySQL service:
    net start MySQL80
    (if your version is different, use MySQL or check Services).
  2. Log in as root:
    mysql -u root -p
    Enter the root password you set during installation.
  3. Run these SQL commands to create the database and user:
    CREATE DATABASE gyropulse CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci; CREATE USER 'aliahsan_admin'@'localhost' IDENTIFIED BY 'Ahsan01_@li'; GRANT ALL PRIVILEGES ON gyropulse.* TO 'aliahsan_admin'@'localhost'; FLUSH PRIVILEGES; EXIT;
    🔑 Password note: The password contains @. In the connection URL (step 6) you must replace @ with %40.

6. Create the .env File

In the project root, create a file named .env with this content:

DATABASE_URL=mysql+pymysql://aliahsan_admin:Ahsan01_%40li@localhost:3306/gyropulse SECRET_KEY=your-secret-key-change-this UPLOAD_DIR=./uploads
⚠️ Important: The password in the URL uses %40 instead of @. If you changed the password, update it here (and encode any special characters).

7. Run the Application

With the virtual environment active, execute:

python app.py

You’ll see output like:

* Serving Flask app 'app' * Debug mode: on * Running on http://localhost:5000
✅ On the first run, the tables and default admin account ( admin / admin123 ) are created automatically.

8. Access the Portal

Open your browser and go to http://localhost:5000.

Log in with:

  • Username: admin
  • Password: admin123

You’ll see the dashboard with stats, messages, and user management.

⚠️ Fix: "Unknown column 'users.city_id'" Error

If you see this error when starting the app, it means your database is missing the city_id column introduced in the latest update.

Fix it quickly with these SQL commands (run in MySQL):

  1. Open MySQL: mysql -u root -p (enter your password).
  2. Select the database: USE gyropulse;
  3. Copy and paste the entire block below into the MySQL prompt:
-- Create cities table CREATE TABLE IF NOT EXISTS cities ( id INT AUTO_INCREMENT PRIMARY KEY, name VARCHAR(100) NOT NULL UNIQUE, created_at DATETIME DEFAULT NOW() ); -- Add city_id to users ALTER TABLE users ADD COLUMN city_id INT NULL; ALTER TABLE users ADD CONSTRAINT fk_users_city FOREIGN KEY (city_id) REFERENCES cities(id) ON DELETE SET NULL; -- Add city_id to products ALTER TABLE products ADD COLUMN city_id INT NOT NULL DEFAULT 1; ALTER TABLE products ADD CONSTRAINT fk_products_city FOREIGN KEY (city_id) REFERENCES cities(id) ON DELETE CASCADE; -- Add city_id to customers ALTER TABLE customers ADD COLUMN city_id INT NOT NULL DEFAULT 1; ALTER TABLE customers ADD CONSTRAINT fk_customers_city FOREIGN KEY (city_id) REFERENCES cities(id) ON DELETE CASCADE; -- Add city_id to orders ALTER TABLE orders ADD COLUMN city_id INT NOT NULL DEFAULT 1; ALTER TABLE orders ADD CONSTRAINT fk_orders_city FOREIGN KEY (city_id) REFERENCES cities(id) ON DELETE CASCADE; -- Insert a default city INSERT IGNORE INTO cities (name) VALUES ('Default City');

After running these, type EXIT; and restart the Flask app – the error will be gone.

⚠️ General Troubleshooting Tips

  • “cryptography is required” → run pip install cryptography and restart.
  • “Access denied” → double‑check the password and that you ran FLUSH PRIVILEGES.
  • “Can’t connect to MySQL” → ensure the MySQL service is running (net start MySQL80).
  • Port 5000 already in use → change port in config.json.
  • “No database selected” → type USE gyropulse; at the MySQL prompt before running SELECT queries, or connect with mysql -u ... -p gyropulse.
  • Tables not found → the app creates them on first run. Make sure you started the app at least once.
