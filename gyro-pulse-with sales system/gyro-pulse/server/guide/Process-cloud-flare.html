1 Bind domain to Cloudflare ▾
  • In your Cloudflare Dashboard, click Add a site and enter tooliport.com (select the Free plan).
  • Cloudflare will scan your DNS and provide two nameservers (e.g. ashley.ns.cloudflare.com and tom.ns.cloudflare.com).
  • Log into Namecheap (or your registrar), find your domain, change Nameservers to Custom DNS, and paste the two Cloudflare nameservers. Save.
⏳ DNS propagation may take a few minutes.
2 Establish the local tunnel (Windows) ▾
  • Go to Cloudflare Zero Trust → Networks → Tunnels → Create a tunnel.
  • Choose Cloudflared, name it home-pc-server, and save.
  • Select Windows 64‑bit and download cloudflared.exe.
  • Move the file to a permanent location, e.g. C:\Users\YourName\.
  • Open Command Prompt as Administrator and paste the exact command shown on the Cloudflare page (it will look similar to):
cloudflared.exe service install eyJhIjoiZTU3...
  • Press Enter – you should see a success message. The tunnel status in the browser will turn green. Click Next.
💡 For Linux/macOS, the command is similar but uses ./cloudflared service install.
3 Publish your application route ▾
  • In the Public Hostname form:
  • Subdomain: api
  • Domain: tooliport.com
  • Path: (leave empty)
  • Service: Type = HTTP, URL = 127.0.0.1:5000
  • Click Save tunnel.
4 Fire up the Go server ▾
  • Open a terminal (non‑admin) in your Go project folder.
  • Run the server with:
go run main.go
  • You should see “Starting Tooliport API Server on 127.0.0.1:5000”.
5 Test the live endpoint ▾
  • From a device outside your home network (e.g. smartphone on cellular), open:
https://api.tooliport.com/api
  • You should see a JSON response with "status": "working" – success!

🧹 How to Safely Stop & Clean Up

1 Stop the Go server ▾
  • In the terminal where the server is running, press:
Ctrl + C
2 Disable or uninstall the Cloudflare tunnel ▾
  • Open Command Prompt as Administrator.
  • To stop the tunnel (without removing it):
sc stop cloudflared
  • To completely uninstall the tunnel service:
cloudflared.exe service uninstall
3 Delete the tunnel configuration in Cloudflare ▾
  • Go to Zero Trust Dashboard → Networks → Tunnels.
  • Click the three dots (…) next to your tunnel and choose Delete.
  • This permanently removes the link between Cloudflare and your machine.
⚠️ Important: The Go server and the tunnel are independent. You can stop the server without removing the tunnel, and vice versa. Always stop the server first if you plan to keep the tunnel.
