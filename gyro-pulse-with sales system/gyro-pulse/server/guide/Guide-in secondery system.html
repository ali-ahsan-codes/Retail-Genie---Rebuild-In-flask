1 Install Prerequisites

  • Python 3.10+ – Download
    ✔ During installation, check “Add Python to PATH”.
  • MySQL Community Server 8.0 – Download (MSI Installer)
    ✔ Select Developer Computer (uses less RAM).
    ✔ Keep ports 3306 and 33060 default.
    🔑 CRITICAL: Set a Root Password (e.g., MyRootPass123!) and write it down.
💡 Tip: If MySQL setup asks for "Windows Service", keep the default settings (MySQL80) and check "Start the MySQL Server at System Startup".

2 Fix 'mysql' not recognized

If you get 'mysql' is not recognized in CMD, it means MySQL is not in your system PATH. Here are 3 fixes:

  1. Option A (Recommended): Use the full path every time. Instead of mysql, type:
    C:\Program Files\MySQL\MySQL Server 8.0\bin\mysql
  2. Option B (Permanent fix): Add MySQL to PATH.
    • Press Win + R, type sysdm.cpl → Advanced → Environment Variables.
    • Under "System variables", find Path → Edit → New.
    • Paste: C:\Program Files\MySQL\MySQL Server 8.0\bin → OK.
    • Restart your Command Prompt.
  3. Option C (Quick): Use the MySQL Command Line Client from the Start Menu.
    4. ✅ After fixing, test by typing mysql --version in CMD. It should show the version.

3 Import Old Database (dump.sql)

Prerequisite: Copy your dump.sql file to the current folder (e.g., C:\Users\YourName\Desktop).

Method: Open Command Prompt (CMD) (NOT PowerShell, as < doesn't work there). Navigate to the folder containing dump.sql and run:

mysql -u root -p gyropulse < dump.sql
  • Explanation: -u root (root user), -p (asks for password), gyropulse (database name), < dump.sql (import file).
  • Enter your Root Password when prompted.
⚠️ If the import fails with "Unknown database 'gyropulse'":
First, create the empty database manually:
mysql -u root -p -e "CREATE DATABASE gyropulse CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;"
Then run the import command again.
🔑 If you used a different username: Replace root with your MySQL username. If you are using aliahsan_admin, make sure that user exists (see Step 4) or use root for import.

4 Create Application User

Your Flask app (.env file) uses aliahsan_admin to connect. We need to create this user in MySQL.

  1. Log into MySQL as root:
    mysql -u root -p
  2. Run these SQL commands exactly:
    CREATE USER 'aliahsan_admin'@'localhost' IDENTIFIED BY 'Ahsan01_@li'; GRANT ALL PRIVILEGES ON gyropulse.* TO 'aliahsan_admin'@'localhost'; FLUSH PRIVILEGES; EXIT;
✅ Now your app will be able to connect using the credentials from .env.
📝 Note for .env: In the .env file, the password must be URL-encoded. Since the password contains @, write it as Ahsan01_%40li.

5 Setup Python Environment

  1. Copy your project folder (containing app.py, requirements.txt, .env) to the new computer.
  2. Open CMD in that project folder.
  3. Create a Virtual Environment:
    python -m venv venv
  4. Activate it:
    venv\Scripts\activate
    (You will see (venv) at the start of your prompt).
  5. Install dependencies:
    pip install -r requirements.txt
  6. Verify your .env file looks like this:
    DATABASE_URL=mysql+pymysql://aliahsan_admin:Ahsan01_%40li@localhost:3306/gyropulse SECRET_KEY=your-secret-key JWT_SECRET_KEY=your-jwt-key UPLOAD_DIR=./uploads BACKUP_FOLDER=./backups
⚠️ Security Alert: The .env file contains passwords. Never share it publicly.

6 Run the Application

Make sure your Virtual Environment is active ((venv) visible). Then run:

python app.py

You will see output like:

* Serving Flask app 'app' * Debug mode: on * Running on http://localhost:5000
  • Open your browser and visit: http://localhost:5000
  • Login with: Username: admin | Password: admin123
✅ You should see your Dashboard with all your imported data!

🛠️ Common Issues & Solutions

❌ ERROR 1045: Access denied for user

Cause: Wrong password, or the user doesn't exist.

Fix: Log in as root and run the CREATE USER and GRANT commands from Step 4 again.

❌ 'mysql' is not recognized

Fix: Use the full path: "C:\Program Files\MySQL\MySQL Server 8.0\bin\mysql" or add MySQL to your system PATH (see Step 2).

❌ The '<' operator is reserved for future use

Cause: You are using PowerShell.

Fix: Switch to classic Command Prompt (CMD) by typing cmd in PowerShell and pressing Enter, or use Get-Content dump.sql | mysql -u root -p gyropulse.

⚠️ Port 5000 already in use

Fix: Kill the process using the port, or change the port in config.json.
