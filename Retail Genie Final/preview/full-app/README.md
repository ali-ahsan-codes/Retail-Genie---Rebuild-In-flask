# Full-app interface previews

These preview images show representative screens from the shared interface system: forest-glass navigation, mineral gradient canvas, consistent cards/panels, controls, tables, and responsive styling. They were captured from a disposable local SQLite demo environment using synthetic records; this is not live-MySQL validation.
